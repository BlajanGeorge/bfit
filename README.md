# B-Fit

A personal fitness app (Be Fit) — **local-only** on the phone, just for me.

- [SPEC.md](SPEC.md) — business logic & flows (source of truth)
- [ASSETS.md](ASSETS.md) — asset spec (muscle-group cards, animations)
- [AGENTS.md](AGENTS.md) — stack, setup, how to run & test in the iOS Simulator
- `data/exercises.json` — exercise catalog
- `assets/muscles/` — muscle-group card images
- `mobile/` — the Expo (React Native + TypeScript) app

## Quick start

```bash
cd mobile
nvm use 20
npx expo start   # press i for iOS Simulator
```
